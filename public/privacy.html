계정과 리뷰 기록

포리뷰어는 개인별 상품, 리뷰 일정, 페이백과 입금 내역을 관리하는 서비스입니다. 로그인한 계정에 다음 정보를 연결해 저장합니다.

  • 가입 시 입력한 아이디 또는 이메일, 비밀번호의 해시값, 가입일과 로그인 세션
  • 이용자가 입력한 상품명, 판매처, 구매 플랫폼, 구매금액, 리뷰 일정과 상태, 리뷰비, 입금 내역, 계정주, 카톡 이름, 메모 등
  • 리뷰 템플릿과 상품 등록 기본값, 상품·리뷰·입금의 변경 이력
  • 내 정보 묶음에 직접 입력한 이름, 플랫폼, 전화번호, 주소, 이메일, 은행, 계좌번호, 예금주와 자동 채움 선택 항목. 주소·연락처·계좌 정보는 선택 입력이며 상품 등록 기본값과 함께 묶음별로 수정·삭제할 수 있습니다.
  • 비밀번호 복구 기능을 설정한 경우 인증 질문과 답변·복구코드의 해시값, 복구 관련 보안 이력

이 정보는 계정 인증, 개인 기록 조회·관리, 통계 표시 및 부정 접속 방지에 사용합니다. 다른 일반 이용자는 내 계정의 기록을 조회할 수 없습니다.

소셜 로그인 정보

로그인 화면에서 제공하는 Google·네이버·카카오 로그인은 선택 사항입니다. 선택한 서비스의 계정 고유 식별값으로 같은 이용자인지 확인하고 포리뷰어 계정에 연결합니다. Google은 기본 인증용 openid, 네이버·카카오는 이용자 식별값을 사용합니다.

  • 저장 항목: 로그인 제공자, 해당 서비스의 고유 식별값, 연결된 포리뷰어 사용자 ID, 연결일과 최근 로그인일
  • 보안 이력: 가입·로그인·연결·해제·본인 확인 등의 종류와 발생 시각
  • 소셜 계정의 비밀번호는 포리뷰어가 받지 않습니다. 이메일·이름·프로필 사진·전화번호는 요청하거나 저장하지 않습니다. Google의 Gmail·Drive·연락처 접근 권한도 요청하지 않습니다.
  • 인증 응답을 서버에서 검증하며, 제공자의 접근 토큰과 ID 토큰은 데이터베이스에 보관하지 않습니다.

소셜 로그인 정보는 로그인과 계정 연결, 보안 확인에만 사용합니다. 광고, 판매 또는 AI 모델 학습에 이용하지 않습니다. 상품·리뷰·입금 내역을 소셜 로그인 제공자에게 보내지 않습니다.

주문내역 이미지와 기기 저장

OCR로 선택한 주문내역 이미지는 이용자의 기기에서 처리합니다. 이미지 원본은 서버에 업로드하거나 저장하지 않으며, 이용자가 등록 폼에서 확인하고 저장한 값이 서버에 전송됩니다.

브라우저에는 로그인 유지에 필요한 쿠키, 열 표시·사이드바 등의 화면 설정, 앱 실행을 위한 정적 파일 캐시가 저장됩니다. 로그인 유지 기간은 최대 7일이며, 로그인 유지를 끄면 서버 세션은 최대 1일 동안 유효합니다. 소셜 로그인 진행용 임시 상태는 10분 동안 유효합니다.

보관과 삭제

계정과 리뷰 기록은 이용자가 다시 조회할 수 있도록 서버 데이터베이스에 보관합니다. 리뷰·입금 내역은 수정 또는 삭제 전후의 이력을 별도로 보관하므로, 상품을 삭제해도 이력이 남습니다.

소셜 계정 연결 정보는 연결을 유지하는 동안 보관합니다. 연결을 해제하면 해당 제공자 고유 식별값의 연결 레코드를 삭제하며, 연결·해제 등의 보안 이력은 계정에 남습니다. 로그인 진행 중인 임시 데이터는 만료 후 다음 인증 요청 또는 매시간 정리 작업에서 삭제합니다.

내 계정 → 회원 탈퇴에서 본인 확인 후 계정 전체를 삭제할 수 있습니다. 탈퇴하면 소셜 연결 정보, 상품·리뷰·입금 기록과 변경 이력, 템플릿 및 설정을 함께 삭제하며 복구할 수 없습니다. 안전한 복구를 위한 암호화 백업에는 삭제 이전 정보가 일정 기간 남을 수 있으며, 정기 백업 작업에서 약 2주가 지난 백업을 순환 삭제합니다.

연결 해제와 이용자 선택

소셜 계정 연결은 로그인 후 내 계정 → 소셜 계정 연결에서 해제할 수 있습니다. 계정 접근을 잃지 않도록 다른 로그인 수단을 먼저 준비해야 합니다. 각 소셜 서비스의 연결 관리 화면에서도 포리뷰어에 대한 승인을 철회할 수 있습니다. 카카오에서 연결을 해제하면 포리뷰어의 카카오 식별값과 해당 로그인 세션도 삭제합니다. 직접 작성한 리뷰 기록은 유지되며, 전체 삭제는 회원 탈퇴에서 진행합니다. 카카오만으로 가입했다면 외부에서 연결을 해제하기 전에 비밀번호 또는 다른 로그인 수단을 설정해 주세요.

상품·리뷰 정보는 서비스에서 직접 조회·수정·삭제할 수 있습니다. 계정 관련 문의, 열람·정정 또는 삭제 요청 시에는 다른 이용자의 정보가 변경되지 않도록 본인 확인이 필요할 수 있습니다.

저장 환경과 보호

서비스와 데이터베이스는 AWS 서버에서 운영합니다. HTTPS 통신, 비밀번호 해시 저장, 사용자별 데이터 접근 확인과 접근 권한을 제한한 데이터베이스를 사용합니다. 운영자는 서비스 지원과 보안 관리에 필요한 범위에서 기록을 확인할 수 있습니다.

소셜 로그인 과정에서는 브라우저가 선택한 로그인 제공자로 이동하고, 포리뷰어 서버가 해당 제공자의 인증 응답을 확인합니다. 그 외에 소셜 로그인 식별값을 외부 업체에 제공하거나 판매하는 기능은 운영하지 않습니다.
