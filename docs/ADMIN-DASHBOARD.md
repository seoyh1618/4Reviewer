# 관리자 대시보드

진입 주소는 `/admin`이며 로그인 후 `/?view=admin`으로 표시한다. 관리자에게만 워크스페이스와 내 계정의 관리자 메뉴가 보인다. 일반 회원이 주소나 API를 직접 호출하면 접근을 거부한다.

## 집계 기준

- 전체 회원: 현재 가입 계정 수. 폐기된 구형 `is_demo=1` 체험 계정은 제외한다. 일반 테스트 계정은 포함한다.
- 월 신규 회원: 한국 시간 기준 선택 월에 가입한 계정.
- 월 활성 회원: 해당 월 로그인·인증된 서비스 이용 기록이 있는 서로 다른 계정 수. 일별 합계를 더하지 않는다. 최근 30일은 오늘 포함 30개 한국 날짜다.
- 월 상품 등록: 등록 시각 기준 이력의 상품 수. 이후 삭제해도 포함한다. 이전 데이터의 baseline은 원래 등록 시각으로 집계한다.
- 상품·리뷰 완료·정산 완료·금액: 현재 상품과 입금 원장의 현황. 리뷰 완료와 정산 완료는 별도 지표다. 금액 없는 정산은 정산 완료에 포함하지 않는다.
- 월 입금액: 현재 유효한 입금 기록의 입금일 기준. 수정·삭제를 반영한다.
- 회원 상세: 현재 상품명·플랫폼·리뷰 타입·상태·금액. 주소·전화번호·계좌번호·비밀번호·토큰은 반환하지 않는다.

`member_daily_activity`에 한국 날짜별 최초/최근 활동을 기록한다. 5분 이내 반복 요청은 시간을 갱신하지 않는다. 관리자 폴링과 건강 검사는 활동을 만들지 않는다. 도입 전 활동은 남아 있는 로그인 시각과 리뷰 변경 이력으로만 복원한다. 계정 삭제 시 활동·권한도 삭제한다.

## 구현 계약

가입·활동 변화와 회원별 이용 규모 비교가 목적이다. 어두운 운영 화면에 저채도 파랑(활성), 민트(가입), 중립 회색을 사용한다. KPI → 일별 선 그래프/플랫폼 막대 → 회원 표/최근 활동 순서다. React가 SVG 그래프 한 개와 DOM 막대 최대 8개를 소유하며 추가 차트 라이브러리는 없다. 관리자 코드·스타일은 지연 로딩한다.

월·검색·정렬·상태는 URL의 `adminMonth/adminQ/adminSort/adminStatus`에 보존한다. 회원은 서버에서 25명씩, 상세 상품은 20개씩 조회한다. 60초 간격으로 갱신하고 숨겨진 탭에서는 멈춘다. 통신 실패 시 마지막 결과와 지연 표시를 유지하며 재연결 시 갱신한다. 권한 회수 시 이전 데이터를 비운다.

모바일(360px 이상)은 KPI 2열, 차트 1열, 회원 요약 카드다. 그래프는 실제 너비에 맞추고 마우스·탭 미리보기 외에 날짜 선택과 일별 표를 제공한다. 키보드 접근, 실제 값 표시, 모션 감소, 넘침을 검증한다. 상세는 초점 제한·복원 기능이 있는 공통 모달이다.

## 권한 운영

`admin_memberships`가 권한 원본이다. 앱 DB 계정은 SELECT만 가능하며 회원가입·프로필 수정으로 권한을 만들 수 없다. 매 API 요청 시 세션과 DB의 현재 권한을 확인한다. 관리자 URL은 noindex, API는 no-store다.

DB 운영자 환경에서 `node server/admin-access.mjs`에 JSON을 표준입력으로 전달해 승인된 계정을 생성/승격한다. 키는 `username`, `password`, `action`(`grant`/`revoke`)이다. 비밀번호를 인자·저장소·로그에 남기지 않는다. 기존 계정은 전달한 비밀번호가 맞을 때만 승격하며 비밀번호를 자동으로 바꾸지 않는다. 공용 demo 승격은 차단한다. 회수는 `action=revoke`이며 다음 요청부터 차단된다.

실제 SQLite/PostgreSQL API 테스트로 비로그인/일반회원 차단, 권한 위조·회수, SQL 권한, 한국 월 경계, 삭제 이력, 입금 정정, 검색/페이지 및 개인정보 제외를 검증한다. 브라우저에서 조회·상세·필터·모바일 카드·차트·접근성을 확인한다.
